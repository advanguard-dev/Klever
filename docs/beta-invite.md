You’re invited to try **Klever** — a local Markdown vault (notes, databases, boards, graph, calendar) that keeps files on your Mac.

**Build:** Klever 0.1.0-beta.1 (Apple silicon only)  
**Download:** [link to zip or attach Klever-0.1.0-beta.1-arm64.zip]

**Install**

1. Unzip, then double-click **Install Klever.command** (or drag Klever.app to Applications).
2. If macOS blocks it or says the app is damaged: Control-click the command or Klever → Open → Open.  
   Or run: `xattr -cr /Applications/Klever.app`

**First run**

Open Klever → **Open sample vault**. That is the quickest tour. Later, **Open folder** on your own Markdown directory.

**AI**

Local mode is the default — no API key needed. Remote AI is optional (DeepSeek) if you want it.
